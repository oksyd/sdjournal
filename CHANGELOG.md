## [Unreleased]

### Breaking Changes

- Raise the minimum supported Rust version to 1.100.0.
- Restrict builds to Unix and Windows targets, removing the unreliable shared-cursor `clone`/`seek` fallback for positional reads.
- Use native systemd cursor text and remove all `SJ1` encodings and legacy cursor recovery rules.
- Return `Cursor` directly from entry cursor methods and `JournalQuery` directly from `seek_cursor`.
- Expose one shared `OrGroupBuilder` and remove the `LiveOrGroupBuilder` alias.
- Replace `LiveFilter` with a shared `Filter` reusable by historical queries and subscriptions.
- Return `Result<tokio::sync::mpsc::Receiver<_>>` from `into_tokio`, removing `TokioSubscription` and reporting forwarding-thread creation failures instead of panicking.
- Initialize replay and resolve starting cursors during subscription registration.
- Retain one committed snapshot boundary when converting a journal into a live engine in either file-access mode.
- Reject malformed cursor UUIDs and propagate non-NotFound directory traversal errors.
- Require partial cursors to contain `s+i` or `t`; reject boot/monotonic-only cursors that cannot provide a reliable cross-boot boundary in this reader.
- Require every opened journal to be sealed through its committed tail before `verify_seal` succeeds; reject unsealed files and tails.

### Bug Fixes

- Fix documentation builds with default features or no default features.
- Require patched mmap and benchmark dependencies in reproducible CI checks.
- Enforce destination filter limits for live-only subscriptions as well as replay and historical queries.
- Validate every field name generated by unit filter helpers.
- Size the Tokio delivery buffer from the subscription's configured channel capacity.
- Preserve unit constraints when adding OR groups, independent of builder call order.
- Reject undersized objects and compression flags on known non-DATA objects at the shared parser boundary.
- Reject committed ENTRY objects with a zero sequence number instead of returning invalid cursors and merge keys.
- Reject unresolved replay cursors even when the journal topology becomes empty.
- Keep live batches fair across hot files, process watcher events during backlogs, and discover files created before watcher installation.
- Preserve polling deadlines across interrupted system calls and close the watcher replacement race.
- Make external integration tests explicitly opt-in and fail on missing prerequisites instead of reporting false passes.
- Propagate background-engine failures in examples and persist checkpoints atomically without clobbering shared temporary paths.
- Require ruzstd 0.9.1 to fix unbounded sequence expansion during Zstd decompression (RUSTSEC-2026-0344).
- Reject reserved Zstd frame descriptor bits and revalidate cached ENTRY_ARRAY layouts during indexed membership checks and seeks.
- Preserve live checkpoints across temporary root-directory disappearance and reject unrepresentable channel capacities before allocation.
- Continue query traversal after recoverable entry or index errors without discarding healthy branches or suppressing other source failures.
- Resolve cursors by logical identity when physical hints or unrelated entry metadata are unreadable.
- Retry previously unreadable live candidates without requiring new watcher events, and distinguish partial root outages from normal journal vacuuming when retaining checkpoints.
- Treat per-file permission failures as retryable during live reading, so one inaccessible file does not stop healthy streams and restored access can resume from its checkpoint.
- Advance live/replay scheduling priority before fallible work so persistent errors on either side cannot starve the other.
- Repair normalized journal and UUID fuzz seeds so they reach entry decoding and cursor round trips; exercise raw journal bytes and fail on fuzz infrastructure errors.

### Refactoring

- Enforce Cargo's unused-dependency lint in the library and fuzz harnesses on Rust 1.100.
- Format cursor IDs without temporary strings, parse verification-key suffixes without allocation,
  and use standard-library slice and checked-alignment operations.
- Update Rust dependencies and remove the obsolete LZ4 `checked-decode` feature while retaining safe decoding.
- Store unit clauses directly instead of expanding combinations, and share cached entry-array indexes across iterators.
- Remove eager entry-range scans and redundant validation/default-value fallbacks after parsing.
- Use the HMAC implementation's verification API for seal tags.
- Declare example feature requirements in Cargo instead of compiling no-op fallback programs.
